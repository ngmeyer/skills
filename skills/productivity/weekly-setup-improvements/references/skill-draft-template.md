# Skill draft template — used by Phase 5

When Section 2 surfaces a skill idea, the report writer materializes a stub at `<WORKING_FOLDER>/_drafts/<skill-name>/SKILL.md` using the template below. The point isn't to *finish* the skill — it's to drop the activation energy from "I should make a skill" to "I should iterate on this draft I already have."

## Why a draft, not a description

V2 ended at "you should build /foo." A week later the user reads it, agrees, doesn't build it, and the same idea recurs in next week's report. The single highest-leverage change is **moving the artifact one step closer to existing**. A stub with correct frontmatter, real trigger phrases lifted from the repetition pattern, and a placeholder procedure is iterate-able. A bullet describing a skill is not.

## Skeleton

```markdown
---
name: <skill-name>
description: <one sentence — what the skill does>. Use when <2–3 specific trigger phrases lifted from the surfaced repetition>.
user-invocable: true
allowed-tools: ["Read", "Write", "Edit", "Bash"]
argument-hint: "[optional argument]"
---

# /<skill-name> — <Title>

<One paragraph: why this skill exists. Cite the specific repetition pattern from the weekly report that justifies it (commit count, file count, prompt count).>

## Procedure

1. <Step — what the user wanted automated>
2. <Step>
3. <Step>

## Output

<What lands on disk or on screen.>

## Gotchas

- TODO: fill in as failure modes emerge.

## Testing

- TODO: add `tests/eval.sh` once the skill earns a second invocation.

---
*Draft generated by /weekly-setup-improvements on <DATE>. Iterate, then promote out of `_drafts/` when it actually fires.*
```

## Rules for the writer

- **Trigger phrases must come from the surfaced repetition.** Not made up. If the weekly audit found three commits with "fix typo in linkedin draft," then `description` should literally include phrases like "linkedin draft", "fix typo", "post-edit pass."
- **One stub per Section 2 idea.** Max 3 idents = max 3 drafts (the V2 cap holds).
- **Don't bloat the stub.** If it's longer than ~40 lines, it's pretending to be a finished skill. Stop.
- **`_drafts/` is iteration space, not the shipping shelf.** A draft only graduates when it actually fires successfully in a real session — then it moves to the canonical skills directory.
